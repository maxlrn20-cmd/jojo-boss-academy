# Jojo Boss Academy

Application de révision de droit (L1) avec le professeur Holly : cours, fiches, Sushi Quiz, flashcards, cas pratiques, examens blancs et progression.

**Site :** https://maxlrn20-cmd.github.io/jojo-boss-academy/

- Un seul fichier `index.html`, sans dépendance ni installation.
- Progression enregistrée dans le navigateur (export / import dans Réglages).
- Sur Mac : ouvrir le site dans Safari, puis Fichier > Ajouter au Dock.
- Sources et licences : [ASSETS.md](ASSETS.md).
